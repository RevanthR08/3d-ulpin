VERTICA input_data_sample

Synthetic mixed-source survey package for the full SIH 3D ULPIN demo.

Drone imagery in this package uses the provided city/campus top-view template images:
- drone/city_core_top_view.png
- drone/city_context_wide_view.png

Demo story:
one upload -> automatic source grouping -> AI pipeline -> 3D parcelization -> floor/unit management -> validation -> ULPIN generation -> registry -> citizen property view.
