# VERTICA Manual Polygon Marker

Standalone helper for manually drawing a building footprint on top of a satellite/drone image.

## Use

Open `index.html` in a browser.

1. Upload an image.
2. Click building corners in order.
3. Click **Close polygon** or press Enter.
4. Download:
   - marked PNG
   - GeoJSON with image-pixel coordinates

This folder is separate from the main VERTICA portal and does not modify backend data.
